# Painel Admin — protótipo (login)

Site estático pronto para **GitHub Pages**: faz upload desta pasta para a **raiz** do repositório e activa *Settings → Pages → Branch: main / Folder: / (root)*.

## Estrutura

- `index.html` — ecrã de login (visual, sem validação)
- `css/` — design tokens Carum, componentes, tema claro/escuro, estilos do ecrã de login
- `js/theme.js` — alternância de tema (guardada em `localStorage`)

Todos os caminhos são relativos à raiz (`css/...`, `js/...`) — não é necessário build.

## Local

Abre `index.html` no browser ou serve a pasta com um servidor HTTP simples.
